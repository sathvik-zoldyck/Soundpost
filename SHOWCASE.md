## Add yours

Two ways:

**1. Pull request (goes in the gallery below)**
1. Add your image to [`docs/showcase/`](docs/showcase/) — PNG or JPG, ideally ≤ 1600px wide, named
   like `yourname-setup.png`.
2. Add a card to the gallery below using the template.
3. Open a PR titled `docs: add <yourname> to showcase`.

**2. Discussion (quick + no PR)**
Post in the [**Show and tell**](../../discussions/categories/show-and-tell) discussion category. We
pull standouts into the gallery.

### Card template

```markdown
### <Your name or handle>
![<short alt text>](docs/showcase/yourname-setup.png)
> Visualizer: Ribbon · Palette: Neon · Theme: default
> A line about your setup — devices, scenes, why you use Soundpost.
> — [@yourhandle](https://github.com/yourhandle)
```

Keep it friendly and real. No fake screenshots, no personal info you don't want public.
