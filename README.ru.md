# Soundpost

### Один центр. Каждый звук.

**Единая консоль для звука в Windows: переключайте устройство вывода, микшируйте каждое приложение и *видьте* свой звук — всё в одном месте. Local-first, без аккаунта, без телеметрии.**

Windows разбрасывает ваш звук по всплывающему регулятору громкости, меню устройств, панели управления звуком и горстке сторонних утилит, которые не общаются друг с другом, — и ни одна из них не помнит, чего вы хотели. **Soundpost — это недостающий центр.** Каждое устройство и каждое приложение стекаются в одну консоль: вы переключаете, микшируете и маршрутизируете — и всё попадает на нужный вывод. А когда хочется просто слушать, визуализатор превращает то, что играет, в нечто, на что стоит смотреть.

## Возможности

- **Мгновенное переключение устройства.** Меняйте устройство вывода или ввода по умолчанию одним щелчком.
- **Микшер по приложениям.** Громкость, отключение звука и живые индикаторы для каждого приложения, издающего звук.
- **Живая индикация вывода.** Пиковые индикаторы — общий и по приложениям — с реалистичной баллистикой.
- **Визуализатор.** Семь живых стилей — Ribbon, Aurora, Spectrum, Radial, Oscilloscope, Cymatics и режим собственного изображения — реагируют на ваш звук на 60 fps, с настраиваемыми чувствительностью, сглаживанием, свечением и палитрой.
- **Полноэкранный оверлей.** Выведите визуализатор поверх музыкального видео с непрозрачным, затемнённым или полностью прозрачным фоном.
- **Быстрая панель.** Компактное всплывающее окно в трее для действий посреди совещания, без открытия полной консоли.
- **Четыре темы.** Indigo, Black & Red, Rich Gold и Cherry Blossom — переключаются вживую из настроек.
- **Локально и приватно.** Без аккаунта, без облака, без телеметрии. Всё остаётся на вашем компьютере.

## Установка

Soundpost рассчитан на **Windows 10 и 11**. Возьмите сборку из [Releases](../../releases), когда она будет опубликована, или соберите из исходников:

```bash
git clone https://github.com/sathvik-zoldyck/Soundpost.git
cd Soundpost
dotnet run --project src/Soundpost.App
```

Понадобится [.NET 9 SDK](https://dotnet.microsoft.com/download). Рабочий процесс релиза создаёт единый самодостаточный `Soundpost.exe` (без установки .NET).

## Как это работает

Каждое приложение и устройство стекаются в один центр; вы маршрутизируете, микшируете и автоматизируете — и всё попадает на нужный вывод. Единый слой Core Audio оборачивает COM-API Windows, чтобы остальная часть приложения никогда не касалась их напрямую, — так консоль остаётся отзывчивой, а обработка звука изолированной и тестируемой.

## Расширяйте

Soundpost создан для дополнения.

- **Визуализаторы.** Стиль — это один класс, реализующий `IVisualizerRenderer` — см. [visualizers/](visualizers/). Напишите, зарегистрируйте — и он появится в панели стилей.
- **Темы.** Палитры — это самодостаточные словари; новая тема — это новый файл плюс образец.
- **Плагины.** Событийная поверхность плагинов есть в дорожной карте — см. [PLUGIN_SDK.md](PLUGIN_SDK.md).

## Дорожная карта

Уже доступно: переключение устройств, микшер и индикаторы по приложениям, визуализатор, трей и быстрая панель, сохранение состояния и темы. Далее: сцены и профили, слой автоматизации, маршрутизация по приложениям и диагностика на понятном языке. Полный план — в [ROADMAP.md](ROADMAP.md).
