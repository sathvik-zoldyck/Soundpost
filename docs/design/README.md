# Design docs

Where design thinking lives — the visual language, UX principles, and flows.

The canonical, enforced design rules are in the [Style Guide](../../STYLE_GUIDE.md#part-2--design)
(color tokens, typography, shape, motion, voice). This folder is for the longer-form *why*: mockups,
explorations, and rationale.

## Principles (short version)

- **A mixing desk, not a settings page.** Tactile, dark, glowing — a premium rack unit.
- **One accent as light.** Amber marks what's active/live/important. Never a fill.
- **Progressive disclosure.** A newcomer sees a clean console; power lives one layer down.
- **Honesty in the UI.** When Windows imposes a limit (a relaunch, latency), the UI says so plainly.
- **Delight is a feature.** The visualizer and live meters exist because a tool people love looking
  at is a tool they keep and share.
