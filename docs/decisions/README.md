# Architecture Decision Records (ADRs)

Short, immutable notes recording a decision we made, the context, and the consequences. When a choice
is settled (often after an [RFC](../rfcs/) or a discussion), we write it down here so future
contributors know *why* things are the way they are — and don't relitigate them by accident.

Format: [Michael Nygard's ADR style](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions.html).
Keep them short. Never edit an accepted ADR to change the decision — supersede it with a new one.
