# README media

Screenshots and GIFs for the top-level [README](../../README.md) and docs. Drop files here, then
enable the matching slot in the README (each image spot is a commented-out `<img>` tag, ready to
uncomment).

## Suggested shots

Use the app's native window ratio, dark background, and keep GIFs short (5–10s) and optimized.

| File | What it shows |
|---|---|
| `hero.gif` | The money shot: switch a device, meters bounce, flip to the Visualizer |
| `mixer.png` | The Mixer tab — device cards + channel strips + master |
| `visualizer.gif` | The Ribbon reacting to music (bonus: cycle a palette) |
| `switching.gif` | One-click output switching |
| `scenes.png` | The scenes bar / applying a scene |
| `diagnostics.png` | Plain-language diagnostics (once built) |

## Tips

- **GIFs:** [ScreenToGif](https://www.screentogif.com/) is easiest on Windows; keep them ≤ ~3 MB.
- **Stills:** PNG, trimmed to the window. 2× (HiDPI) looks crisp on GitHub.
- Name files exactly as above so the README slots line up.
